> 技术栈：Rust / TUI

你现在不是在“给我设计建议”。

# 27. State 与 UI 解耦

UI 不应该自己管理核心业务状态。

原则：

```text
App State
    ↓
UI derives presentation
    ↓
Widget
```

而不是：

```text
Widget
    ↓
修改核心业务逻辑
```

UI 组件尽可能：

* 接收状态
* 生成展示
* 触发已有 action

不要让 UI 组件重复实现业务逻辑。
