# voicefox 0.8.1 更新说明（2026-10-30）

> 二轮审查与加固批次：修复慢速网络下载大文件必然超时的功能缺陷，兑现
> `?`/F1 帮助键的文档承诺，统一 16 处裸锁的毒化恢复策略，文档能力矩阵
> 对齐实际实现。基线验证：`cargo fmt --check` 绿、528 个测试全绿
> （voicefox-app 466 / lx-core 43 / lx-lyric 19）、
> `cargo check --target x86_64-pc-windows-gnu` 绿。

## 修复

### 下载超时（功能缺陷）

下载引擎此前把 `[network].timeout`（默认 15 秒）设为 HTTP client 的**整体**
超时——它覆盖整个响应体读取，单连接流式下载只要总时长超过它就被掐断：
慢速网络下大 FLAC/MP3 必失败，且重试同样超时。

现在的语义：

- 控制请求（源能力探测、元数据、小封面）仍受 timeout 约束；
- 流式下载只约束「等待响应头」与「字节停滞」（超过 timeout 秒没有新数据才
  判失败），总时长不再受限。

### 帮助键

README 与 KEYBINDINGS.md 承诺的 `?` / `F1` 打开快捷键帮助此前只有 `\\` 一个
实际绑定。现已注册 `?` 与 `F1`（`\\` 保留为别名，不破坏存量习惯）。

### 锁毒化级联

代码库的主流策略是 `unwrap_or_else(|e| e.into_inner())` 恢复毒化锁，但有
16 处漏网——config 读锁会被媒体控制线程写入（存在真实跨线程毒化源），
播放解析路径的换源索引锁在每次切歌时触达。全部统一为毒化恢复，消除
「单线程 panic → UI 全崩」的级联路径。

### 健壮性与性能

- 酷狗搜索先校验 HTTP 状态再解析 JSON：429/网关 HTML 不再被误归类为
  解析错误（影响重试判断）；
- 歌词/搜索的异步任务 panic 时向用户发通知（此前静默消失）；
- MPRIS 更新服务 panic 补日志、错误回退路径撤掉嵌套 unwrap；
- 队列页 Enter/播放选中歌改用 Arc 共享（万首队列每次按键省一次全量克隆）；
- 底栏下载指示改锁内轻量摘要（每帧不再深克隆全部任务视图）。

## 文档对齐

能力矩阵修正两处虚标（哔哩哔哩 / Jamendo 的歌词标注 ✓ 但实现是桩，现改为
—）；四处音源的歌单能力精确为「搜索/详情」（无热门歌单浏览入口）；Apple
Music 的专辑能力补上（代码有专用实现，原文档低估）。KEYBINDINGS.md 修正
历史页清空键（实际是 `D`/`Shift+D` 双击确认，非 `Shift+X`）并补录此前
漏记的按键（队列 `f`、`Shift+>`/`Shift+<`、排行榜 `←/→` 等）。

## 升级说明

- 无配置变更、无数据迁移，替换可执行文件即可；
